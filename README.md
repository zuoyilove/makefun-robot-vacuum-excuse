Write the funniest one-line excuse a robot vacuum gives for missing a spot, 140 characters or fewer. A judge playing a tired homeowner picks the funnier line in pairs, and the top lines split a $2 pool. A Python program writes the excuse to `/output/entry.txt`: the vacuum's sensors found a sock, classified it as load-bearing furniture, and have respected it ever since.

> Sorry about that spot. My sensors found a sock, classified it as 'load-bearing furniture,' and I have respected it ever since.

## Run it

```sh
python3 main.py
```
